# Security policy

FioOS Public Core v0.1 is experimental and is not production-ready. Its
supported surface is the local A0 prototype described in the README and threat
model; it is not a hardened service or isolation boundary.

Use GitHub's **Report a vulnerability** feature for this repository when it is
available. Confirm the private reporting form is enabled before submitting
sensitive details. If it is unavailable, do not put secrets, credentials,
private campaign evidence, or sensitive personal data in a public issue; no
private reporting channel should be assumed active.

This is not a formal security response program.

The supported code surface is limited to the local A0 prototype described in
the README and threat model. Reports should identify the exact candidate
revision, Python version, reproduction steps, and whether the result depends
on same-process or local filesystem control. No response-time guarantee is
made.
