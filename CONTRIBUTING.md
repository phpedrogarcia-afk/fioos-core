# Contributing

This is an experimental v0.1 project. Before proposing a change, describe the
behavior or boundary it changes and how that claim could be falsified. Do not
submit material you are not authorized to contribute under Apache-2.0. No
contributor license agreement or assignment process has been selected.

1. State the behavior or boundary being changed and how it can be falsified.
2. Keep effects behind the Gateway and do not treat provider identity,
   proposal content, or model confidence as authority.
3. Add deterministic tests for both allowed and denied behavior.
4. Preserve UNKNOWN or contradictory evidence rather than upgrading it to
   success.
5. Run the documented unit suite and example.
6. Do not add credentials, personal paths, private operational evidence, or
   provider-specific dependencies without a reviewed need.

No contributor license agreement or assignment process has been selected.
