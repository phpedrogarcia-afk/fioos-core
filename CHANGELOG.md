# Changelog

## 0.1.0 — Experimental governance core

- Prepared a dependency-free local reference for untrusted proposals,
  controller-owned A0 policy, mandatory Gateway mediation, and correlated
  effect results.
- Deliberately excluded private lab adapters, campaign evidence, cloud
  identifiers, provider credentials, and general-purpose shell execution.
- Licensed under Apache-2.0 with human-owner authorization to distribute the
  included original FioOS material.
- Experimental and local-only: no production readiness, distributed
  exactly-once, multi-host durability, or long-running service suitability is
  claimed. Two LOW availability risks are accepted only for finite, trusted
  local v0.1 experiments; see `docs/CLAIMS_AND_LIMITATIONS.md`.
