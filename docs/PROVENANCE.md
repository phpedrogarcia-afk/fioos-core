# Provenance and extraction record

This repository is a sanitized public extraction of the FioOS governance core.
It is a narrow local reference implementation, not the private FioOS
laboratory. Private experimental source coordinates, campaign evidence, raw
receipts, and account-specific configuration are intentionally excluded.

The included implementation re-expresses selected project governance concepts
for one local A0 effect path. The human project owner explicitly authorized
distribution of the included original FioOS material under Apache-2.0 and
confirmed, to the best of their knowledge, that no incompatible third-party
code is included. This is an authorization record, not independent legal
advice or a claim of complete historical provenance. The bounded file-level
review and its limits are in
[`PUBLICATION_PROVENANCE.md`](PUBLICATION_PROVENANCE.md).

No third-party source or vendored package was identified in the bounded files
reviewed. The CI workflow references pinned upstream GitHub Actions;
their implementations are fetched by GitHub Actions and are not copied into
this repository. The license decision note contains links to canonical license
references, not copied license texts. Python dependency information is listed
separately in [`../DEPENDENCIES.md`](../DEPENDENCIES.md).

The human owner's authorization and the Apache-2.0 text in `LICENSE` govern
this release. The bounded review does not establish rights beyond the stated
authorization, provide legal advice, or replace future provenance review if
new material is added.
